Swagger יפתח בכרטיסייה חדשה עם גישה מלאה לכל ה-endpoints

💡 טיפים לשימוש ב-Swagger:

  • אימות: לחץ על "Authorize" בראש העמוד והזן: Bearer YOUR_TOKEN
  • לקבלת token: פתח Developer Tools (F12) → Console → הקלד: sessionStorage.getItem('authToken')
  • השתמש ב-"Try it out" כדי לבצע קריאות API ישירות
  • כל ה-endpoints מתועדים עם דוגמאות ושגיאות אפשריות
  • ניתן להוריד את ה-OpenAPI spec בפורמט JSON או YAML
